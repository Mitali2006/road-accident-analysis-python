# Road Accident Analysis and Safety Trends Using Python 🚗📊

## Overview
This project analyzes road accident data to identify patterns, major risk factors, and trends that influence accident severity and casualties. Using Python and data science libraries, the dataset was cleaned, visualized, statistically tested, and used for predictive modeling.

## Dataset 📁
The dataset contains **3000 accident records** with features such as:

- State Name 🗺️  
- Number of Casualties 🚑  
- Number of Fatalities ⚠️  
- Speed Limit (km/h) 🛣️  
- Driver Age 👤  
- Accident Severity 🚨  
- Weather Conditions 🌦️  
- Road Type 🛤️  
- Road Condition 🧱  
- Lighting Conditions 💡  
- Alcohol Involvement 🍺  
- Traffic Control Presence 🚦  
- Accident Location Details 📍

## Statistical Methods Used 📐
- Shapiro-Wilk Test  
- Chi-Square Test  
- T-Test  
- IQR Outlier Detection  

## Machine Learning 🤖
A **Linear Regression model** was developed to predict the number of casualties using selected features such as speed limit and accident location.

## Key Insights 💡
- Higher speed limits are associated with more casualties.  
- Alcohol significantly impacts accident severity.  
- Weather and road conditions affect accident outcomes.  
- Poor lighting conditions may increase casualty risk.
